**המגבלה שהתגלתה מייד באימות הזה — נסגרה (2026-09-06).** תקרת 200 השורות חתכה את הקובץ באמצע והבעלים ביקש להמשיך לקרוא, ולא הייתה דרך לבקש את ההמשך. התקרה בוטלה, ובמקומה שני מסלולים:

- **`search_email_attachment`** — סורק את הקובץ **כולו** בזרימה ומחזיר רק שורות תואמות. `keywords` בקשר "או", `must_also_match` בקשר "וגם" מולן, כדי להצליב ערים מול אנשים. שבע ערי הטריטוריה מוגדרות ב-`CITY_ALIASES` עם הקיצורים והתעתיקים, וההתאמה מנרמלת כתיב מלא/חסר, גרשיים, מקפים ואותיות סופיות. ההתאמה על מילים שלמות ולא תת-מחרוזת — אחרת `לוד` ו-`Lod` היו מתאימים בתוך מילים אחרות.
- **`read_email_attachment(..., part=N)`** — קריאה מלאה בחלקים ממוספרים, כשכל חלק אומר כמה חלקים יש ואיך לבקש את הבא.

**גם השליחה בוואטסאפ תוקנה באותו מהלך:** Meta דוחה גוף הודעה מעל 4,096 תווים, והדחייה רק נרשמה ללוג — כלומר תשובה ארוכה הגיעה לבעלים כשקט מוחלט, שנראה בדיוק כמו עוזר שמתעלם. עכשיו התשובה מפוצלת להודעות ממוספרות.

**כיסוי הבדיקות:** 90 בדיקות עוברות, כולל המרה של קובצי `xlsx`/`docx`/`pdf` אמיתיים שנבנים בתוך הבדיקה עצמה (לא Mock של ספריית הפענוח), וכולל את שרשרת ה-Gmail מול מבנה הודעה אמיתי עם `attachmentId`.
